## 📌 Project Overview

The **Sales Management System for University Students** is designed to manage and organize sales-related data efficiently within a university environment.  
This system helps students record, update, search, and manage sales information in a structured and user-friendly manner.

The project focuses on **data organization, efficient searching, and management operations**, making it suitable for academic use and small-scale sales tracking scenarios.

---

## 🎯 Objectives

- 📦 Manage sales records efficiently  
- 👨‍🎓 Support student-based sales activities  
- 🔍 Enable quick search and retrieval of sales data  
- 🧮 Automate calculations and summaries  
- 📊 Improve data accuracy and organization  

---

## ⚙️ System Features

- Add new sales records  
- Update existing sales details  
- Delete sales records  
- Search sales information  
- Display all stored records  
- Simple menu-driven interface  

---

## 🛠️ Technologies Used

- **Programming Language:** C++  
- **Data Structures:** Linked List (Doubly Linked List)  
- **Development Environment:** Any C++ Compiler (GCC / Dev-C++ / Code:Blocks)  

---

## 🧠 Implementation Details

- Sales records are stored using a **doubly linked list** for efficient traversal.
- Each node represents a sales record with relevant details.
- The system supports dynamic memory allocation.
- Operations such as insert, delete, search, and display are implemented using linked list logic.
